## Limits and follow-up

Version-28 animation entries now support editing and verified Save As. Other content types remain read-only. Whole-animation creation/duplication and texture import/replace are not implemented. Animation playback approximates collision/physics, launch context, facade rendering, lights, fog, camera parameters, screen effects and nonspatial audio; gameplay callbacks are trace-only. Edited ZBDs have not been tested in the original game. Static world browsing does not implement full game behavior. LOD is selected manually per object; camera-distance transitions and fading are not simulated. The horizon hierarchy is hidden by default in the overview; its original static geometry is retained in world exports.

The Windows computer-use helper was unavailable (native pipe connection failed). WPF integration and render checks ran successfully, but pointer/keyboard workflows, file dialogs, and multi-monitor DPI transitions still need hands-on review. The portable package has not been tested on a separate clean Windows 11 machine. The build is unsigned.

The historical Python CLI 105/105 byte-identical round-trip claim was not revalidated. Desktop parse/export checks do not establish game round-trip compatibility.
