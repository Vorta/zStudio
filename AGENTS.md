# zStudio

Build a Windows 11 x64 desktop asset explorer and content-specific editor. The explorer milestone is documented in `docs/implementation-plan.md`; the version-28 animation editor and preview are documented in `docs/animation-editor.md`. Use C# 14, .NET 10, WPF, and a separate format library. The former Python CLI is archived outside this repository. Only optional independent export validation uses Python; normal builds/tests and the application do not.

Vorta/zStudio is a public open-source repository. Work on branches, link relevant issues, review changes, and require passing CI before squash-merging. Follow the active main and release-tag rules; do not bypass or weaken them to land changes. Check `docs/releasing.md` for release tags and repository maintenance. Keep the existing MIT license and notices. The solution is zStudio.slnx and project folders/files use zStudio.*. Explicit AssemblyName and RootNamespace properties preserve internal Recoil.Zbd.* identities, embedded resources and friend assemblies; RecoilZbdStudio settings paths remain stable.

Preserve pre-existing changes. Never write into `zbd_1998/`, `zbd_1999/`, or the external reconstruction/decompilation projects. Do not commit game assets, extracted assets, build output, or corpus reports. Exports must not overwrite source files or escape the selected destination.

Treat ZBD as five separate format families. Probe binary structure and version, not just filenames. Preserve record identities, ordering, unknown data, and source ranges. Names are not unique. Stored pointer values are metadata, never process pointers. Verify disputed semantics against available engine evidence and the private reconstruction/decompilation references described in `docs/architecture.md`; historical notes are provisional. These external references are not build dependencies and must not be committed.

Use nullable types, explicit little-endian bounded reads, cancellation, deterministic exports, and actionable diagnostics. Keep binary models independent of UI and rendering dependencies. Add meaningful malformed-input and corpus tests. Do not claim engine compatibility from a successful parse alone.

Animation edits must preserve untouched bytes and record order, keep runtime simulation state separate from serialized data, and support undo and verified Save As to a new file outside the source dataset. The primary sequence is cleanup, not an extra runtime sequence. Retail event 0x16 releases a waiting sequence and 0x17 stops it. The historically named Object3D SetLitFlag controls the inherited alpha override; do not reintroduce unconditional stored-opacity rendering. Mark game-dependent preview approximations explicitly.

Procedural launch ranges at bytes 32/40/48/56 are yaw/pitch/speed/radial acceleration, verified directly in retail 0x459E70; the reconstruction's temporary names and initial gravity branch are inaccurate. Forward is -Z. Flag 1 enables signed gravity at byte 24; 0x2000 selects its transposed world basis. Keep active one-shot sounds in seek snapshots until their WAV duration ends so mute and pause/resume do not drop them. Animation audio defaults to unmuted.

Prepare animation audio from a frozen dependency snapshot, including child animations, branches and cleanup. Decode only reachable samples off-thread and reuse a single warm mixer/output. Sound cues, pause, mute and seek must not initialize or dispose native audio devices on the UI thread. Preserve independent voice cursors and generation checks across cancellation, seek and asynchronous shutdown.

Build: `dotnet build zStudio.slnx`. Test: `dotnet test --solution zStudio.slnx`. Packaging and corpus checks are in `tools/`. Update `docs/status.md` and the local `.agent` status at meaningful milestones with actual results and remaining limitations. The old CLI's round-trip claims do not establish desktop application acceptance.

Animation transport uses plain Space from Assets or passive preview content without stealing native text/button/slider behavior. Keep transport icons beside the seeker at narrow widths. Duration analysis runs on a snapshot and must never mutate source data or advance the visible player. Distinguish finite preview duration from looping, waiting, unavailable and bounded-analysis ranges; do not restore a fixed duration for every asset.

Before a ZBD root is opened, show the welcome screen and hide workspace panes/actions/search without changing saved layout preferences. The Fluent workbench has one Navigator (Files/Assets/Search/Document scene), central preview with persistent transport, one Inspector with animation tabs (Sequences/Settings/References), and a separate explicitly opened Properties window, and bottom tools (Dispatch/Event log/Problems/Runtime/Related/Bytes). The Files tree owns open-document navigation: mark open/active/dirty files and provide row close buttons, retaining save/discard guards. Opening a file from Files switches to Assets. Search input belongs to Search; do not restore document tabs. Keep the single title/menu row aligned, with full-height caption controls and a Windows maximize/Snap hit region. Properties uses one reusable, owned, modeless window for all viewers. Open it through a row context menu or View/Alt+Enter. Keep its document/record identity pinned across selection and preview replacement; never bind editable fields to the active row or keep a hidden renderer alive for properties. Resolve popup drafts before retarget/save/close, including clean documents with pending input. Commands in Properties target its owning document, with native text undo retained. Keep only icon Undo/Redo controls at the top right of the Properties breadcrumb row, with a trimmed single-line heading and full-context tooltip. Do not restore its bottom button row or a docked Properties pane; window X closes it, and document-scoped Ctrl+S remains available. Keep grouped native ToolBar overflow, source selection by stable entry/sequence/event identity, separate runtime markers and asset export selection. Cleanup selection must not switch playback phase. Hide/show, resizing, theme and density changes must not replace/dispose the editor or commit drafts. Preferred pane dimensions/groups/tabs persist; automatic narrow collapse never overwrites them. Contextual scalar/compound drafts commit on Enter or an intentional field boundary, with inline validation, Escape restore, and explicit resolution before navigation/save/close. Preserve unknown bits, inactive stored fields, authored rates and record order. Original-source Bytes is bounded to 4096 bytes and explicitly distinct from edited properties and runtime memory. Problems retain emitter-supplied severity/source context; dispatch logs retain distinct occurrence identities and disclose caps.

The right animation tabs are Sequences, Settings and References, in that order. Entering animation preview defaults to Sequences; consecutive animation selections preserve the selected right tab. Properties is a separate window with saved size/position; it is closed at startup and closes when its document is disposed. Hide the entire right pane for non-animation viewers. Properties never consumes workspace space. Ignore obsolete Properties pane height settings. Realizing the retained tree selection when opening its tab is presentation work, not new source navigation or a draft commit. Ignore obsolete Program pane height preferences. Describe stored event operands without mutating records or resolving names as unique identities; reference indices remain visible. Timing rows are clock thresholds, not durations or observed dispatch times. Preserve child-wait flags and condition/loop integer-versus-float semantics in descriptions. Recent-folder paths must render literally, including underscores, rather than interpreting them as menu access keys.

Hide Assets when no file is open and hide Document scene unless the active document has scene roots. Move away from a selected tab before hiding it: use Assets if a document remains, otherwise Files. Preserve an existing Files/Search selection on document changes.

Keep the current document name followed by Undo, Redo and Save icons centered in the single title/menu row. Reserve menu/caption hit regions equally on both sides; trim long names with a full-path tooltip. Hide the group without a document. Do not restore a separate folder/document command row or duplicate Save As/Export/Validate buttons; these remain in File/Tools. Root selection remains in File/Open folder and Ctrl+O. The bottom Cancel button and manual indexing cancellation were removed at the user's request. Escape first exits captured freecam, otherwise cancels an active pickup drag. Otherwise Tools/Escape cancellation is only for active exports or validation; it must not cancel loaded preview lifetimes. Retain automatic cancellation on workspace/document replacement and application shutdown. Problems separates file/operation issues from preview/resource/support notices; Event log contains observed dispatches and Runtime contains current simulation state.

Fly camera captures input only on explicit activation in model/Whole world previews, never through scene-option refresh. WASD moves along the camera basis, Space/C along world Y, mouse movement looks around, and wheel adjusts speed without translating. Normalize combined movement and integrate elapsed time with no inertia; speed must not depend on surface hit distance. Desktop owns foreground raw mouse/cursor capture with a recentered fallback for absolute/remote input; Rendering owns motion math. Release all held input, cursor confinement and capture on Escape, deactivation, focus/capture loss, unavailable/replaced previews and shutdown. Keep the final pose on exit, synchronize the icon and speed hint with actual state, and support overflow activation. Do not persist active capture or add this mode to animation previews.

Portable packaging uses `tools/publish.ps1`: exactly `zStudio.exe` and `dependencies/` at the ZIP root. Keep managed/native runtime files, documentation and license notices inside dependencies. Use the SDK apphost's relative DLL binding, not a wrapper process or a custom assembly resolver. The program icon is the checked-in `src/zStudio.Desktop/Assets/studio.ico`, copied from the user-supplied Studio icon.

Texture cycles may be created at runtime: saved materials, mission `tex_fx` interpreter setup, then `effects.zrd` setup, in that order. Effect setup changes shared material bindings (fire_bft uses the fire1 material); retain those bindings separately from serialized GameZ data. Preload cycle maps and keep cycle sampling deterministic when seeking. Transparent textures without an alpha plane key decoded RGB565 zero when flag 2 is set. Alpha blending must retain opaque depth writes but avoid depth writes for transparent surfaces, including alpha-zero texels. Keep the explicit input layout on the custom Helix alpha pass.

LOD 0 means the nearest/highest-detail authored band for each parent group, not one global map distance. Higher ranks clamp independently per object. Animation LOD selection only changes visible poses, preserving inactive variants' simulation state. Model previews and exports use the enclosing LOD group where present. Keep map/model/animation picker behavior consistent.

Mission previews use a separate single-player starting scene for the shared, saved Easy/Medium/Hard preference (default Medium): load-time flagged cleanup and automatic activations, per-instance turret cleanup, AIV vehicle instances/poses, pickup placements, then the immediate NEW_GAME_START animation frontier. Select authored aiv_easy/aiv/aiv_hard and vehicle_easy/vehicle/vehicle_hard ZRD resources, with independent default-file fallbacks only when variants are absent. Keep requested difficulty and effective resources in context/cache identity and labels. Do not merge layouts or infer difficulty from actor name suffixes. The inspected retail 0x41FE40 returns aiv.zrd; authored AIV variant selection is a Studio preview capability, not verified engine parity. Never advance mission context time or play startup audio to recover a pose. Background actors stay at their starting layout. Unplaced scripted actors are hidden in world context until placed; individual inspection may use a clearly labeled stored-pose fallback. Names do not identify instances; retain source-node provenance when cloning vehicles. Shared world animation bindings must share state and checkpoint aliases, while copied animation roots/effects retain separate identities. Source data remains untouched.

Turrets use ai.zrd numeric wildcard patterns (each star is one decimal digit), with resolved explicit destruction animation, named turret animation, then global default precedence. Apply its primary cleanup to the actual instance; an absent animation name must not resolve the reserved empty entry. Scope reset components to that turret and retain destroyed geometry for later animation playback. Hide initialization-only fire-point/effect helpers without deleting source records.

Mission pickups use the engine's 40-type catalog at retail 0x4DB6E8 and puNNN model templates. Select puppies_easy/puppies/puppies_hard independently with default fallback only when absent. These resources contain ordered placement lists, not name/value pairs. Preserve XYZ, radian Euler rotation, template scale, amount/default amount and respawn metadata; hide bvol collision geometry. Show all authored pickups regardless of player inventory. Bind clones by archive/resource/record identity and template provenance; different pickup resources must not remap by generated name or clone index. Never simulate collection/respawn or terrain snapping to invent a starting placement.

Whole world pickup editing uses a separate PickupPlacementEditSession and renderer instance transforms, never mutations of the cached mission baseline or shared mesh transforms. New map documents start Locked. A drag is one undoable move; Escape during that drag cancels only the drag. Match difficulty counterparts uniquely by original type/position/rotation, preserve links through edits, and deduplicate fallback resources. Save patches only coordinate nodes in owning ZAR archives (m1 uses zrdr.zbd), with reparsing, unrelated-byte verification and external-change checks before atomic replacement. Explicit pickup Save may replace a working archive; zbd_1998/zbd_1999 remain protected. Optional backups default off. Save As uses new destinations and retargets subsequent saves. Keep existing export and animation Save As protections. Unsupported GameZ-authored pickups remain inspectable.

Difficulty changes preserve playhead/playback, free camera or followed camera, grid/height, LOD, custom range and authored selection. Remap bindings/inspection only through unambiguous actor identity and source provenance, never old clone indices. Keep audio resources/output warm. Superseded requests cannot publish; a request cancellation token must not become the lifetime of a successfully loaded animated viewport. Animation and Whole world toolbars begin with LOD, an unlabeled difficulty picker, then Frame; difficulty shares one saved app preference.

The horizon follows the active viewport camera (XYZ for the Player horizon fallback, or explicit XZ-only binding). Render it before scene geometry without depth writes or scene near/far clipping; exclude it from framing/depth bounds. Animation world poses must obey the Horizon checkbox. Invalidate the frozen preview context after edits. Keep only the current portable folder and ZIP in artifacts after delivery; put transient verification reports in the OS temporary directory or remove them after validation.

Finalize preview cameras after Helix controller/inertia updates and before render-context matrix capture. Camera notifications only invalidate; they must not recursively reapply animation poses. Depth bounds come from visible transformed geometry, refining intersecting model bounds with triangle clipping; world AABBs cannot determine a useful near plane from inside a map. Keep navigation clearance independent. Cameras are always upright around +Y with ±89° pitch, including authored preview poses; preserve the orbit target or Fly/authored position. Idle regression captures must read the presented back buffer without forcing a render or resize.

Camera animation channels use ordinary translation and rotation semantics: the historical engine names SetTarget (+0x14) and SetPosition (+0x20) mean translation and Euler rotation respectively in transform mode. Retail Class.c 0x4496AE passes them as position/angles; Camera.c 0x44ABF0 derives the eye from the world matrix and forward from its negative Z basis. Never treat Euler angles as eye coordinates or translation as a look-at target. Stored/event horizontal FOV is radians; convert to degrees at the preview-frame boundary. Camera keyframes must retain parent transforms and deterministic seeking. Follow camera toggles apply immediately while paused.

Animation Show grid and Flat-ground collision are independent Desktop controls, both checked by default; Core callers opt into GroundPlaneEnabled. Grid visibility only changes rendering. Collision changes reconstruct the current playhead and invalidate duration/checkpoints. It is a world Y=0 plane, not terrain or camera collision. Mesh-based contact includes morph/scale/spin and all authored LOD variants; independently moving descendants are excluded. Keep the landed support latch in checkpoints and retain it through shrink/sink, with no extra impact cues. Retail 0x45A4DB–0x45A6C0 gates both release 0x800 (208/240) and impact audio 0x1000 (242/244) on contact. Preload collision samples and preserve cue gain on seek/resume. Ground toggles rebuild at the current playhead, preserve custom range/playback, and invalidate duration/checkpoints. Grid must not participate in picking, framing or near/far bounds.

Animation Height defaults to 0, accepts −999 to 999 game units, and is preview-only. Negative offsets lower the animation; the grid and collision plane stay at Y=0. Keep event/simulation coordinates authored; apply its world-Y offset once to output poses/effects/lights/cameras/audio and to ground-support measurements. Do not translate serialized records or the static map. Height changes reconstruct the playhead, duration and checkpoints with prior playback/custom range retained. Keep the Grid shader independent of scene far distance, antialiased, depth-tested without depth writes; only its pass disables depth clipping and clamps output depth. Document Undo/Redo/Save commands live above the workspace. Viewport toggles use individually named Fluent icon buttons with native checked/unchecked states and tooltips; compact/comfortable hit targets are 32/40 DIP. Grid, Height and independent collision move together in native overflow. Keep one authoritative control per option: no toolbar Settings button or duplicate presentation/audio controls in Settings. Settings retains binding/mission information, execution, activation points, preview range and support. Whole world/model previews use the same icons and styles, preserving pickup locking.

Height applies valid values on TextChanged without Enter or blur. Hide the Fluent clear button without changing single-line text behavior; reapply on template/theme replacement. Temporary empty/incomplete/invalid input must retain the last valid preview height without errors or caret changes. Normalize to that value on an intentional keyboard-focus boundary or Enter/Escape; overflow reparenting, layout, menus and window deactivation must retain partial text and caret.
