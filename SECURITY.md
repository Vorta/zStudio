# Security policy

The latest released version of zStudio receives fixes. Earlier 0.x versions may require updating rather than a backport. The application parses binary files; reproducible crashes caused by invalid data are useful reports even if exploitability is unknown.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/Vorta/zStudio/security/advisories/new) to send a confidential report to the maintainer. Do not post exploit details in public issues. If the reporting form is unavailable, open an issue requesting that it be enabled without including sensitive details.

Include the affected release, reproduction steps, expected impact, and a minimal synthetic input where possible. Do not attach proprietary game files, decompilation databases, personal information or credentials. No response-time guarantee is currently offered.
